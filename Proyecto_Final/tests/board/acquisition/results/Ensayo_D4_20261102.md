# Ensayo integrado D4: 02/11/2026

Rama feat/d3-estimacion, base 3f9822a con los cambios locales D4 sin commit.
NUCLEO-WL55JC, Zephyr 4.4.2, SDK 1.0.1, GCC 14.3.0. El perfil independiente
tests/board/acquisition enlaza el servicio y los algoritmos reales; el main
solo consulta la API y controla begin/end. Compilo con -Wall -Wextra -Werror
y se grabo/verifico con STM32CubeProgrammer 2.23.0. FLASH 46484 B, RAM 9792 B.

El usuario confirma los tres sensores conectados. LDR a 3,3 V sin pull-down
adicional de 47 kohm, referencias provisionales 4062/128. Consola COM5,
115200 8N1. Adquisicion conserva prioridad 3, stack solicitado 2048 B y timer
de 20 ms; observador prioridad 4, stack 3072 B. INIT_STACKS y THREAD_STACK_INFO
se habilitan solo en el perfil de ensayo para observar el margen de pila.

ya hay IMU/nav validas y cal=0; ENV vuelve a renovarse. Esa captura no contiene
el instante de reconexion ni acredita el primer dt=0 de la retoma.

## Correccion de coordinacion ambiental

Se añaden tres lineas a acquisition_environment_update: si el bus no esta
permitido y ready_ticks<0, retornar false sin desplazar el vencimiento ni
invalidar una medida ambiental previa. Se sigue omitiendo I2C en esa vuelta.
Si habia conversion pendiente, se conserva la cancelacion/reprogramacion
existente. No se añaden fechas, estados, hilos ni algoritmos de sensores.

La prueba host ambiental se amplio para repetir revisiones fallidas a 1 s
y comprobar que ENV inicia/recoge en las siguientes vueltas permitidas.
Fallo antes del ajuste (CHECK de la linea 204) y paso despues; las seis suites
host pasaron en Debug. Produccion y ensayo recompilaron correctamente.
El ensayo corregido usa FLASH 46476 B y RAM 9792 B; produccion 35876/8768 B.

SHA256 del HEX previo: E047D2AB6EECFFAD1BF8FA80E51453F7C01FA165D33CFB0EA7F4B3CEBA20B66B.
SHA256 del HEX corregido: 3429D3F571A4B259C88CFFB6B03A76E49A0622C06D4A2FC2F105B799D419AB5D.

Se grabo/verifico la imagen corregida y se dejo la IMU quieta durante el
