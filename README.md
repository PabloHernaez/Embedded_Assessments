# Embedded Assessments

En este repositorio reunimos las entregas de Embedded Platforms and IoT:

- [Assessment 1: iluminación](Assessment_1/README.md).
- [Proyecto final: drone tracker](Proyecto_Final/README.md).

Trabajamos en el proyecto final con
[Proyecto_Final.code-workspace](Proyecto_Final.code-workspace). El workspace
abre `Proyecto_Final` como carpeta de trabajo y detecta el repositorio Git
superior. Así mantenemos las rutas de compilación y depuración dentro del proyecto.

En la [documentación de desarrollo](Proyecto_Final/docs/README_DESARROLLO.md)
registramos el entorno, los perfiles, el reparto del trabajo y los pendientes.
