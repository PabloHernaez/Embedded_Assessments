# Embedded Assessments

- [Assessment 1: iluminacion](Assessment_1/README.md).
- [Proyecto final: drone tracker](Proyecto_Final/README.md).

Para trabajar en el proyecto final con VS Code, abrir
[Proyecto_Final.code-workspace](Proyecto_Final.code-workspace). Este archivo
selecciona `Proyecto_Final` como carpeta de trabajo para las tareas de
compilacion, programacion y depuracion. Tambien se puede abrir directamente
la carpeta `Proyecto_Final`. El workspace activa la deteccion del repositorio
Git de la carpeta superior para el control de versiones.

Las dos entregas pertenecen a este mismo repositorio Git.
